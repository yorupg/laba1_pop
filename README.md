Лабораторная работа №1

Описание проекта

В рамках лабораторной работы был разработан Python-пакет toolkit с интерфейсом командной строки (CLI).
Программа состоит из двух независимых утилит:

Калькулятор — вычисляет арифметические выражения, введённые пользователем.
Конвертер — переводит значения между различными единицами измерения.

Интерфейс командной строки реализован с помощью библиотеки Typer. Все вычисления выполняются собственными функциями без использования eval() и exec()

Требования и зависимости

Для работы проекта необходим Python версии 3.12 или выше
Проект использует менеджер зависимостей uv и следующие библиотеки:

Зависимость	      | Назначение
Python 3.12+	  | Язык программирования, на котором написан проект.
Typer	          | Создание интерфейса командной строки (CLI).
pytest	          | Автоматическое тестирование программы.
uv	              | Установка зависимостей и управление виртуальным окружением проекта.

Установка зависимостей:

После скачивания проекта необходимо установить все зависимости командой: uv sync
Команда uv sync создаёт виртуальное окружение (если его ещё нет) и устанавливает все зависимости, указанные в файле pyproject.toml

Возможности программы:

Калькулятор

Калькулятор поддерживает:

1 целые и вещественные числа (int и float)
2 операции сложения (+), вычитания (-), умножения (*) и деления (/)
3 унарные знаки чисел
4 пробелы в выражении (они игнорируются)
5 правильный порядок выполнения операций: сначала умножение и деление, затем сложение и вычитание

Конвертер

Конвертер выполняет перевод между единицами трёх категорий.

Поддерживаемые единицы:

Длина:

mm — миллиметры
cm — сантиметры
m — метры
km — километры

Масса:

g — граммы
kg — килограммы

Температура:

c — градусы Цельсия
f — градусы Фаренгейта
k — Кельвины

Регистр единиц измерения не учитывается: пользователь может вводить KM, Km, kM или km.


Описание алгоритма решения задачи:

Алгоритм работы калькулятора:

1 Пользователь вводит арифметическое выражение через команду python -m toolkit calc
2 Функция validator() проверяет выражение на наличие ошибок
3 Если ошибок нет, функция tokenizator() разбивает выражение на список чисел и список операторов, если есть - выводит сообщение об ошибке
4 Функция calculator() сначала выполняет все операции умножения и деления
5 Далее выполняются операции сложения и вычитания
6 Полученный результат возвращается пользователю

Алгоритм работы конвертера:

1 Пользователь вводит значение, исходную единицу измерения и единицу, в которую нужно выполнить перевод
2 Функция get_category() определяет категорию единицы (длина, масса или температура)
3 Проверяется, относятся ли обе единицы к одной категории
4 Функция convert() выполняет перевод по формулам для выбранной категории
5 Если перевод невозможен, пользователю возвращается сообщение об ошибке

Принятые решения при реализации проекта

Во время разработки проекта были приняты следующие решения:

1 Разделение программы на модули

Программа разделена на несколько файлов, чтобы каждая часть отвечала только за одну задачу

validator.py — проверка корректности выражения
tokenizator.py — разбиение выражения на числа и операторы
calculator.py — выполнение вычислений
converter.py — перевод единиц измерения
constants.py — хранение всех поддерживаемых единиц измерения
errors.py — хранение сообщений об ошибках
__main__.py — запуск программы через командную строку

Такое разделение делает код более понятным и удобным для тестирования

2 Использование библиотеки Typer

Для создания интерфейса командной строки была выбрана библиотека Typer. Она позволяет создавать отдельные команды (calc и convert), автоматически обрабатывать аргументы командной строки и выводить справку по программе

3 Проверка выражения до вычислений

Перед вычислением выражение проходит проверку в функции validator(). Это позволяет обнаружить ошибки до выполнения вычислений и вывести пользователю  сообщение об ошибке

Проверяются:

пустое выражение
отсутствие чисел
пропущенный оператор между числами
двойные операторы
недопустимые символы
деление на ноль
ошибки записи чисел

4 Использование токенизации

Для разбора выражения используется функция tokenizator(). Она преобразует строку в два списка:

список чисел (float) и список арифметических операторов

После этого калькулятор работает уже со списками, а не со строкой.

5 Приоритет арифметических операций

Вычисление выполняется в два этапа:

           сначала умножение и деление
           затем сложение и вычитание

Это позволяет реализовать правильный порядок вычислений без использования встроенных функций вычисления выражений.

6 Использование регулярных выражений

Для поиска чисел, операторов и ошибок ввода используются регулярные выражения (re). Это позволило проверить корректность выражения до начала вычислений.

7 Константы ошибок и единиц измерения

Все сообщения об ошибках вынесены в файл errors.py, а все единицы измерения - в файл constants.py. Благодаря этому одинаковые строки не повторяются в разных частях программы.

8 Автоматическое тестирование

Для проверки программы используется библиотека pytest. Отдельные тесты написаны для калькулятора, конвертера и интерфейса командной строки.

Обработка ошибок

Программа проверяет корректность введённых данных и выводит сообщения об ошибках

Обрабатываются следующие ситуации:

пустое выражение
отсутствие чисел в выражении
пропущенный оператор между числами
двойные операторы
недопустимые символы
деление на ноль
ошибка ввода, если в числе больше одной точки
несовместимые единицы измерения
неизвестная единица измерения
неверное числовое значение
температура ниже абсолютного нуля

При возникновении ошибки сообщение выводится в stderr, а программа завершается с кодом 2.


       Ошибка                     |    Пример
Пустое выражение	              | " "
Пропущен оператор между числами   |	"12 12"
Два оператора подряд	          | "1 ** 5"
Недопустимые символы	          | "2 + abc"
Деление на ноль	                  | "5 / 0"
В числе больше одной точки	      | "48..5"
Нет чисел в выражении	          | "++-+"
Несовместимые единицы измерения   |	--from kg --to km
Неизвестная единица измерения     | --from kg --to mg
Температура ниже абсолютного нуля |	-280 --from c --to k
Неверное числовое значение	      | отрицательная масса или длина

Описание файлов проекта:

calculator.py:
Содержит функцию calculator(), которая вычисляет арифметическое выражение с учётом приоритета операций

validator.py:
Проверяет корректность введённого выражения и обнаруживает ошибки до начала вычислений

tokenizator.py
Разделяет строку выражения на список чисел и список арифметических операторов

converter.py:
Определяет категорию единицы измерения и выполняет перевод между единицами одной категории

constants.py:
Содержит кортежи со всеми поддерживаемыми единицами измерения

errors.py:
Хранит все сообщения об ошибках в виде констант

tests/:
Содержит автоматические тесты для проверки калькулятора, конвертера и интерфейса командной строки.

__main__.py:
Создаёт интерфейс командной строки с помощью библиотеки Typer и обрабатывает запуск команд calc и convert

Примеры работы программы:

Калькулятор

Корректные выражения:

python -m toolkit calc "2 + 2*2"
Вывод: 6.0

python -m toolkit calc "10 / 4"
Вывод: 2.5

python -m toolkit calc "1 + -2"
Вывод: -1.0

Примеры ошибок:

python -m toolkit calc "2 + asd"
Вывод: недопустимый символ

python -m toolkit calc "5/0"
Вывод: деление на 0 запрещено

python -m toolkit calc "48..5"
Вывод: ошибка ввода, в числе больше одной точки

Конвертер

Корректные переводы:

python -m toolkit convert 1000 --from g --to kg
Вывод:1.0 kg

python -m toolkit convert 0 --from c --to k
Вывод: 273.15 k

Примеры ошибок:

python -m toolkit convert 1 --from kg --to km
Вывод: данный тип не поддерживается

python -m toolkit convert -280 --from c --to k
Вывод: ниже абсолютного нуля

Тесты

Для проверки работы программы используются автоматические тесты библиотеки pytest

Тесты проверяют:

1 корректность вычислений калькулятора
2 обработку ошибок калькулятора
3 правильность перевода единиц измерения
4 обработку ошибок конвертера
5 работу команд командной строки (CLI)

В проекте реализованы тесты для калькулятора, конвертера и интерфейса командной строки

Запуск тестов осуществляется с помощью команды: pytest

После запуска pytest автоматически найдёт все файлы из папки tests и выполнит все тесты проекта

Запуск программы:

Калькулятор:
python -m toolkit calc "арифметическое выражение"

Пример:
python -m toolkit calc "2 + 2*2"

Конвертер:
python -m toolkit convert VALUE --from UNIT --to UNIT

Пример:
python -m toolkit convert 10 --from km --to m

Справка по программе:
python -m toolkit --help

Команда выводит список доступных команд и описание их аргументов
